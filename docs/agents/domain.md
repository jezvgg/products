# Domain Docs

This is a single-context repository.

Before exploring code:

- Read `GLOSSARY.md` at the repository root if it exists.
- Read relevant ADRs under `docs/adr/`.
- Use glossary terminology in issues, specs, tests, and implementation notes.
- Surface conflicts with existing ADRs instead of silently overriding them.

Missing glossary or ADR files do not need to be created proactively.
